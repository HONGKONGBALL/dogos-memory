## 借鉴的源码

| 上游 | 本项目借鉴 | 首版处理 |
|---|---|---|
| `memory_structures/associative_memory.py` | memory stream；event/chat/thought 三种节点 | 统一到 SQL `memories.kind` |
| 同文件 `ConceptNode.node_id` | 记忆 ID | 使用控制层稳定 ID，增加幂等冲突检查 |
| 同文件 `created`、`description` | 时间、文字内容 | `occurred_at_ms`、`content`；另记入库时间 |
| 同文件 `poignancy` | 重要性 | 保留 1–10 字段，不增加模型打分调用 |
| 同文件 `filling` | 印象所依据的证据 ID | 规范化为 `memory_evidence` 与首条证据外键 |
| `cognitive_modules/retrieve.py` | 按当前情境取回相关记忆 | 先实现固定对象 + 最近时间，不复制三因素加权 |
| `cognitive_modules/reflect.py` | 根据已有经历形成印象，并记录证据 | 实现有证据的 thought 存储；未实现自动调用模型 |

## 明确未搬入的部分
